## Phase 2: Visual Design
*   **Theme Application**: "Solar Ink & Deep Orbit"
*   **Colors**:
    *   Background/Surfaces: Deep Graphite Void (`#0B0F17`, `#111827`, `#161F30`)
    *   Primary Accents: Solar Coral (`#FF6B35`), Electric Cyan (`#00F0FF`), Golden Hour Amber (`#FDBA74`)
    *   Text: High-contrast (`#F8FAFC`), Muted (`#94A3B8`)
*   **Typography**:
    *   Headlines: `Be Vietnam Pro`
    *   Body: `Anybody`
    *   Code/Data: `Domine`
*   **Layout & Spacing**:
    *   12-column grid on desktop, 6 on tablet, 1 on mobile
    *   8px baseline rhythm (`space-xl` for containers)
*   **Elevation & Shapes**:
    *   Hairline borders `rgba(255, 255, 255, 0.08)` turning colored on hover.
    *   Glows: Solar/Cyan glows on interactive elements.
    *   Border radius: 8px for standard, 16px for cards, full for pills.
*   **Components**: Style buttons, chips, playground cards, inputs, and interactive project cards.

## Stage 4: Components & Interactivity Refinement
- **Objective:** Implement and fine-tune functional domain components and responsive interactions.
- **Key Components:**
  - Terminal Shell block with prompt prefix (`> run`), title bar, and command status markers.
  - High-priority Projects showcase matrix (visually prominent centerpiece).
  - Status chips and technical stack tags with monospaced metadata.
  - Mobile-responsive navigation with accessible, reachable Call-to-Action at phone widths.
  - Contrast and accessibility validation (minimum 4.5:1 ratio for body text).
- **Deliverable:** Fully responsive, accessible, interactive web application.
- **Exit Criteria:** Explicit user confirmation to proceed to Stage 5.
