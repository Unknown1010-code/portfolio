## design
- **Aesthetic Theme**: "Solar Ink & Deep Orbit" — fusing high-contrast modern brutalism, celestial void aesthetics, and luminous solar neon accents.
- **Color Palette**:
  - Background Canvas: Deep Graphite Void (`#0B0F17`, `#0F131C`)
  - Elevated Surfaces & Cards: `#111827`, `#161F30`, `#1E293B`
  - Primary Accent: Solar Coral / Radiant Tangerine (`#FF6B35` / `#FFB59D`)
  - Secondary Accent: Electric Cyan / Orbit Blue (`#00F0FF` / `#00EEFC`)
  - Tertiary Accent: Golden Hour Amber (`#FDBA74` / `#FCB973`)
  - Typography Colors: Crisp White (`#F8FAFC`, `#DFE2EE`) and Muted Slate (`#94A3B8`)
- **Typography Engine**:
  - Headlines & Display: `Be Vietnam Pro` (geometric, tight tracking, high-impact)
  - Body & Editorial: `Anybody` (clean, modern horizontal metrics)
  - Code, Telemetry & Chips: `Domine` (monospaced rigor, technical precision)
- **Elevation & Geometry**:
  - Hairline borders (`1px solid rgba(255, 255, 255, 0.08)`) with dynamic hover glow transitions.
  - Atmospheric neon glows: Solar Coral halo (`0 0 24px -4px rgba(255, 107, 53, 0.35)`) and Cyan halo (`0 0 24px -4px rgba(0, 240, 255, 0.35)`).
  - Consistent border radii: 8px (`0.5rem`) for buttons/inputs, 16px (`1rem`) for cards, full capsule (`9999px`) for badges/chips.

## Responsive behaviour
- **Fluid Layout**:
  - Mobile (`< 768px`): Single-column stack, 1rem (16px) margins, compact padding.
  - Tablet (`768px - 1024px`): 6-column grid layout, 1.5rem gutters.
  - Desktop (`> 1024px`): 12-column fluid grid, 2rem gutters, max container width `80rem` (1280px).
- **Touch Targets**: Minimum 44x44px touch targets on mobile devices for buttons, links, and filter pills.
- **Dynamic Text Scaling**: Responsive typography ensuring headlines scale smoothly without clipping or horizontal overflow.

## behaviour
- **Interactive Feedback**: All clickable elements (buttons, cards, chips) provide immediate visual feedback via hover lift, glow, and active states.
- **Smooth Navigation**: Smooth scrolling between sections with clear visual focus indicators for keyboard accessibility.
- **Glassmorphic Micro-Interactions**: Ambient background gradient shifts, subtle hover shine effects on primary CTAs, and active telemetry dot pulses on ML badges.
- **Phase-Aligned Execution**: Respect the 5-phase delivery pipeline (Page Structure -> Visual Design -> Real Content -> Micro-Interactions -> Polish & Optimization).
